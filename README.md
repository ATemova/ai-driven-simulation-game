# 🧬 AI-Driven Simulation Game

An agent-based simulation where autonomous agents move, consume resources,
and survive based on simple decision rules — producing emergent behavior.

## Features
- Deterministic simulation (seeded RNG)
- Autonomous agents with energy, vision, and movement
- Resource (food) spawning and consumption
- Emergent population dynamics
- Modular engine + systems architecture

## Tech Stack
- TypeScript
- Node.js
- ts-node

## Run Locally
```bash
npm install
npm run dev
